# 数据中心风光储—柔性算力协同调度研究

> **研究设计 v2（已确认）**：研究算力侧不确定性与联合能源侧不确定性下，风电、光伏、储能和柔性批处理负载的日前协同调度。碳强度被定位为剩余购电的消费侧环境属性，以碳预算约束和事后实际排放评价呈现。
>
> **实现状态（必须区分）**：`scripts/run_four_windows.py` 已实现主线的确定性日前 MILP：预测风光、BESS、有效回放容量和预测碳预算；随后以实际风光和实际碳强度做固定计划回放。联合风光碳残差、SAA、静态 Γ-RO 和所提 DRO 尚未迁移到该主线，故当前结果是主线的确定性基准，不能作为不确定性方法的最终比较结论。

## 1. 研究问题与边界

**主问题**：在 Alibaba v2018 trace 驱动的聚合数据中心场景中，如何在批处理工作负载的到达、时长和可调度能量存在不确定性时，利用风电、光伏和储能，在满足并网、爬坡、储能和有效回放容量约束的前提下，降低购电成本并满足预设碳预算？

研究采用**反事实、小时级、单数据中心调度情景**：Alibaba trace 提供负载形状与柔性证据；ERCO 系统风光提供本地风光资源的时序代理；储能与风光容量为预设敏感性场景。它不是实测数据中心或实测本地电站的生产部署研究。

本研究的季节维度仅用于四个能源情景窗口（1/4/7/10 月）的样本外稳健性检验。各窗口使用同一条 trace 驱动的工作负载生成机制，**不声称 Alibaba 工作负载具有季节性**。

## 2. 方法定位与可检验命题

论文创新聚焦于**不确定性处理与调度优化**，而非多目标加权、削峰或预测模型本身。

1. 基于 trace 的聚合柔性需求和有效回放容量，能够构造物理容量闭合的可复现实验场景。
2. 相比确定性、独立 SAA 和静态 Γ-RO，保留风、光、碳预测误差相关性的联合能源不确定方法，能够更好地权衡成本、碳预算违反和并网约束违反。
3. 上述折中在四个样本外能源窗口中具有情景稳健性；这不构成工作负载季节性的统计结论。

只有在明确给出模糊集/分布歧义集、标定规则和样本外回测后，论文才使用 “DRO” 一词；在此之前，应诚实称为情景 RO 或 Γ-RO。

## 3. 数据与变量角色

### 3.1 算力侧：Alibaba cluster-trace-v2018

- 现有主要输入：`batch_task.csv`、`container_meta.csv`、`machine_meta.csv`；`batch_instance.csv`、`container_usage.csv`、`machine_usage.csv` 不作为本阶段必需数据。
- `batch_task` 的起止时间、计划 CPU 和任务规模用于构造**聚合批处理能量与可调度窗口的情景代理**，不把观测完成时刻写成真实 SLA/deadline。
- 在线负载目前只能由 `container_meta` 的静态预留近似；不额外引入未经数据标定的在线负荷不确定性。

### 3.2 能源侧：ERCOT/EIA

- 电价：ERCOT `LZ_HOUSTON` 日前电价。
- 实际系统信号：EIA ERCO 的 `erco_solar_generation_mwh`、`erco_wind_generation_mwh` 和 `erco_consumed_co2_intensity_lbs_per_kwh`。
- 日前信号：`forecast_erco_*` 由滚动 Ridge 预测器从保护期前的同类实际历史生成，**不是**交割时段实际值的复制。详见 [docs/forecasting.md](docs/forecasting.md)。

系统风光仅被用作本地反事实资源的**出力形状代理**。本地容量由场景参数给定，缩放参考值必须在训练/标定期固定，不能按每个 30 天窗口各自峰值归一化。

### 3.3 风、光与碳的分工

| 量 | 物理角色 | 模型位置 |
| --- | --- | --- |
| 本地风电、光伏出力 | 供给侧，减少购电 | 功率平衡、弃风弃光、储能与可行性 |
| 电网消费侧碳强度 | 剩余购电的平均排放属性 | 碳预算、事后排放核算 |

碳排放只计算为剩余购电乘以碳强度。风光通过减少购电降低核算排放，不再另计一份“风光碳收益”。消费侧平均碳强度不等于边际排放因子，故不应声称等量真实边际减排。

## 4. 建模主线

### 4.1 有效回放容量

Alibaba 的计划/预留资源在聚合后不与物理核数闭合。主实验采用有效回放容量：

\[
C^{\mathrm{eff}}=\kappa C^{\mathrm{physical}},\qquad
\kappa\in\{0.6,0.7,0.8\},\qquad C^{\mathrm{physical}}=387{,}264\ \text{cores}.
\]

保持原始在线/批处理形状，并以统一缩放系数使峰值不超过 $C^{\mathrm{eff}}$；调度中还需显式满足在线负荷与批处理负荷之和不超过该容量。该做法是可解释的情景归一化，不是实测利用率恢复。

### 4.2 双侧不确定性

- **算力侧**：批处理到达、时长、能耗/资源需求和聚合柔性窗口的不确定性。
- **能源侧**：风、光和碳强度的日前预测误差。

不把静态在线负载再单列为第三种核心不确定性。若需要，可用在线负荷增加 5%/10%/15% 的压力测试检验鲁棒性，但须标注为情景分析。

能源侧残差以同日 24 小时块保存：

\[
\xi_d^{E}=(r_{d,1:24}^{PV},\ r_{d,1:24}^{W},\ r_{d,1:24}^{C}).
\]

该形式保留风、光、碳误差的时序相关性与互相关性。不能把三个误差分别按独立的统一百分比扰动；太阳能 24.3% NMAE 仅描述当前点预测准确度，不能替代联合不确定集。

### 4.3 目标与约束

主模型以购电成本为目标，并施加预测碳预算：

\[
\min\ C_{\mathrm{op}}=
\sum_t p_tg_t\Delta t+
c_{\mathrm{deg}}
\sum_t\left(x_t^{ch}+x_t^{dis}\right)\Delta t,
\qquad
\text{s.t.}\quad \sum_t g_t\hat c_t\le (1-\eta)E^{\mathrm{base}}.
\]

其中 $\Delta t=1$ h 为当前固定的小时步长，$\eta\in\{0,5\%,10\%\}$ 为预先设定的碳预算情景。$c_{\mathrm{deg}}$ 是按累计充电量与放电量的总吞吐量计的 BESS 衰减成本：一次充、放各 1 MWh 合计为 2 MWh 吞吐，直接相加、不除以 2。当前原型默认 $20$ USD/MWh 吞吐，主敏感性为 $10/20/40$ USD/MWh。它是透明的研究情景，不是 CAPEX 年化或市场报价。每小时的 BESS 只能充电或放电。风光、储能和批处理决策进入功率平衡；并网功率、爬坡、SOC、有效回放容量、能量守恒与柔性窗口共同定义可行性。事后以实际风光和实际碳强度回放，报告真实核算排放及碳预算违反率。

本文研究既定风光储配置下的调度，不作容量投资决策。因此，风光与储能的固定运维成本及年化投资成本均不计入目标函数和成本降低率；在主比较中它们对所有方法都是相同常数。这里的成本仅指调度相关运行成本，不能解释为全生命周期或平准化成本。

完整目标模型与不确定集见 [docs/model.md](docs/model.md)。

## 5. 实验设计

主比较保持资产配置一致，以隔离调度与不确定性方法的贡献：

1. 无能源感知的固定负荷基线；
2. 确定性日前调度；
3. SAA；
4. 静态 Γ-RO；
5. 所提联合能源不确定方法。

报告日前购电成本、BESS 吞吐衰减成本、调度相关运行成本及（仅鲁棒模型）保护函数项；成本下降率一律按调度相关运行成本计算，不以固定运维或年化投资成本抬高分母。另报告事后购电量、实际消费侧核算碳排放、碳预算违反率、并网/爬坡违反率、弃风弃光、批处理能量完成情况和求解时间。风光储容量、$\kappa$、碳预算强度和鲁棒度参数均做敏感性分析；四个能源窗口是外部稳健性检验而非创新点。

## 6. 当前实现状态与路线

| 项目 | 当前仓库 | 主线所需状态 |
| --- | --- | --- |
| 本地风光 | 预测风光按 2024 P99 固定参考值缩放 | 固定参考尺度的本地反事实风光场景 |
| BESS 成本 | 默认 $20$ USD/MWh 累计吞吐衰减成本，输出单列 | 与容量、时长和吞吐成本共同敏感性分析 |
| 碳 | 预测碳预算约束，实际碳回放与违反量 | 联合残差下的碳风险约束 |
| 能源不确定性 | 确定性日前预测 + 实际回放 | 风光碳联合日块残差集、SAA、静态 Γ-RO 与 DRO |
| 算力容量 | 有效回放容量 $\kappa=0.7$ 与统一缩放 | $\kappa\in\{0.6,0.7,0.8\}$ 敏感性 |
| 结果 | 四窗口确定性主线基准 | 不确定性方法的统一比较结果 |

当前主线入口为 `scripts/run_four_windows.py`，输出 `data/results/four_windows_mainline_summary.csv`。下一阶段只需新增并冻结 2024 年风光碳联合日块残差，再将 SAA、静态 Γ-RO 与所提方法接到同一日前—实际回放接口；在此之前不使用 “DRO” 描述当前确定性基准。

## 7. 诚实边界

- 调度不改变 IT 总计算量；改善的是购电时序、成本、消费侧核算排放和并网运行指标。
- 风光容量、储能参数、有效回放容量和碳预算均是可复现情景参数，不是现场测量。
- EIA 的风光与碳信号是 ERCO 平衡区系统级信号，不等同于数据中心地理位置的实测资源或物理购电来源。
- 由于没有任务提交时间、SLO 和真实 deadline，不能声称保证真实生产 SLA。
