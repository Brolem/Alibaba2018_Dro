# 主线论文图表清单（待重跑）

> 本清单对应“联合算力与风光不确定性下的成本—运行可靠性”主线。碳排放只作环境绩效输出；旧 PV+BESS 与碳预算数字仅作开发档案。

## 论文叙事

1. Alibaba trace 驱动的工作释放轨迹与有效回放容量形成可复现的柔性算力可调度域；
2. 能源侧决定低成本风光资源何时可用，算力侧决定柔性需求届时能否实际调用；
3. 双侧不确定性在固定总工作量条件下共同约束风光储—算力日前调度，其必要性由 $2\times2$ 机制消融检验；
4. 四个能源窗口检验样本外情景稳健性，而非工作负载周期性或季节性。

## 统一报告口径

- 每种方法使用相同的风光储容量、工作负载生成种子和有效回放容量；
- 算力训练与回放均来自相同 7 个完整源日，只通过预注册且互不重叠的种子隔离，统一称为“同源、种子隔离的重采样评价”；
- 算力侧随机原语是归一化工作释放轨迹，累计包络由同一轨迹派生；不独立扰动上下包络，不声称识别了工作负载周期性；
- 日前优化只使用预测风光；预测碳强度只核算名义计划排放，事后使用实际风光和实际碳强度；
- 碳排放是消费侧平均碳核算，不报告“边际减排”；
- 成本统一为购电成本加 BESS 吞吐衰减成本，并分别报告；风光储固定运维与年化投资成本因主比较的资产配置相同而不计入目标函数或成本降低率；鲁棒保护项单列、不参与调度相关成本下降率；$c_{deg}$ 是研究情景参数，不是 CAPEX 年化或市场报价；
- 正文数值至少报告跨窗口均值、范围和违反率，不能只选一个窗口；
- 除非获得真实时限/SLO 数据，不报告“生产 deadline 保证”或真实 SLA 违反率。
